# App Store screenshots 1.2

This folder contains six screenshots at each requested iPhone size and a six-up contact sheet.

- `1260x2736/` — large-display screenshots.
- `1179x2556/` — medium-display screenshots.
- `contact-sheet.png` — small-size visual review of the six large-display screenshots.

All PNGs are opaque sRGB. The screenshots retain the existing captions, colors, fonts, and order. Each includes the complete centered iPhone frame.

Source app: version 1.1 (40), commit `2da0f08c7991460e27a9880893d30b8b7e00d086`. The Daily Goals screen was captured at the top of Settings to avoid the earlier scroll artifact. No App Store Connect upload or submission was performed.
